## 📌 Featured Projects

### 🧪 TestSphere — Automated Software Testing Platform

An automated software testing platform designed to manage and organize the software testing lifecycle.

**Key Features & Goals:**
- Test Case and Test Suite Management
- Automated Test Execution using Pytest
- Browser Testing with Playwright
- Execution History and Reports
- Defect Tracking and Management
- Release Readiness Monitoring
- Multiple Projects and Environments

**Technology Stack:** React, TypeScript, Python, Django REST Framework, SQLite, Pytest, Playwright.

### 📄 DocuFlow — Document Verification System

A document intake, OCR processing, and verification system designed to streamline document review workflows.

**Key Features & Goals:**
- Document Upload and Processing
- OCR-Based Text Extraction
- Editable OCR Results
- Document Validation
- Duplicate Document Detection
- Reviewer Approval Workflow
- Audit Trail and Reporting

**Technology Direction:** Python, Django, PostgreSQL, OCR.
